# 拾光 · 校园失物招领

拾光是一个校园失物招领网页。你可以发布寻物或招领信息，浏览、搜索和筛选物品，查看详情与联系方式，并在物品找回或归还后更新状态。项目使用原生 HTML、CSS 和 JavaScript，可直接在浏览器中运行。

## 功能

- 发布寻物和招领信息，填写物品、地点、日期、描述及联系方式。
- 按关键词、信息类型、物品类别、地点和处理状态查找信息。
- 查看物品详情，一键复制发布者的联系方式。
- 在“我的发布”中管理信息，将寻物标记为“已找到”、招领标记为“已归还”。
- 页面适配电脑和手机屏幕。

## 目录说明

仓库中包含 `index.html` 的文件夹是网页目录。以下结构从该文件夹开始：

```text
.
├─ index.html          网页入口
├─ favicon.svg         浏览器标签页图标
├─ css/
│  └─ styles.css       页面样式
├─ js/
│  ├─ app.js           页面渲染和交互
│  └─ store.js         数据校验、搜索筛选和本地存储
├─ tests/
│  └─ store.test.js    核心逻辑测试
├─ docs/               开发与测试资料
├─ screenshots/        图片资料
├─ 双击打开网页.bat     Windows 快速启动脚本
└─ run-tests.bat       Windows 测试脚本
```

## 运行方法

1. 下载并解压整个仓库，找到包含 `index.html` 的文件夹。
2. 用 Google Chrome 打开 `index.html`。无需安装依赖或启动服务器。
3. Windows 用户也可以在该文件夹中双击 `双击打开网页.bat`。

## 使用方法

1. 在“信息广场”浏览物品；输入关键词，或选择类型、类别、地点和状态进行筛选。
2. 点击信息卡片查看详情，按需复制联系方式并联系发布者核实。
3. 点击“发布信息”，选择“寻物”或“招领”，填写必填项后提交。
4. 在“我的发布”中查看自己发布的信息。物品找回或归还后，及时更新状态。

首次打开会显示 6 条示例信息。新发布的信息及状态保存在当前浏览器的 `localStorage` 中，刷新页面后仍会保留；不同浏览器或设备之间不会同步。需要恢复初始示例信息时，可在 Chrome 开发者工具的 **Application → Local Storage** 中删除 `campus-lost-found-v1`，然后刷新页面。

## 运行测试

安装 Node.js 18 或更新版本后，在包含 `index.html` 的文件夹中运行：

```powershell
node --test tests/store.test.js
```

Windows 用户也可以双击 `run-tests.bat`。运行网页本身不需要 Node.js。
