## 三、核心功能

- 发布“寻物”或“招领”信息。
- 首页集中浏览全部失物招领信息。
- 支持按物品名称、描述、地点、类别等关键词搜索。
- 支持按信息类型、物品类别、地点、处理状态进行组合筛选。
- 点击卡片进入详情页查看完整信息。
- 查看发布者主动提供的联系方式。
- 一键复制联系方式，减少手动抄写错误。
- 在“我的发布”中管理自己发布的信息。
- 寻物信息解决后可标记为“已找到”。
- 招领信息解决后可标记为“已归还”。
- 状态更新后会在首页、搜索结果和详情页同步显示。
- 使用浏览器 `localStorage` 保存发布信息和状态，刷新后仍然保留。
- 对空搜索、缺少必填项、描述过短等情况提供明确提示。

## 四、核心使用流程

```text
发布寻物 / 招领信息

招领 → 标记“已归还”
        ↓
首页和搜索结果显示最新状态
```

## 十、附加特点

### 1. 多条件组合筛选

除了关键词搜索，还可以根据：

- 寻物 / 招领
- 物品类别
- 地点
- 进行中 / 已解决

进行组合筛选。相比只靠关键词，可以更快缩小范围。

### 2. 一键复制联系方式

详情页支持直接复制发布者联系方式，不需要手动抄写，也不需要额外实现即时聊天系统，符合本次作业的功能边界。

### 3. 状态明确可见

已经找回或归还的信息会显示“已找到”或“已归还”，避免其他同学继续进行无效联系。

### 4. 本地持久化

使用 `localStorage` 保存发布内容和状态修改，刷新页面后数据不会立即丢失。

### 5. 响应式布局

页面针对常见笔记本宽度和较窄屏幕进行了适配，在不同窗口尺寸下仍可正常使用。
